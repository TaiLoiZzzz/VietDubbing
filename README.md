# VietDub AI - Thuyết Minh & Lồng Tiếng Video YouTube Tự Động

Tiện ích mở rộng Chrome lồng tiếng, thuyết minh video YouTube trực tiếp bằng giọng đọc tự nhiên (Microsoft Edge-TTS / Azure Neural) và dịch thuật tự động tốc độ cao.

## ✨ Tính Năng Nổi Bật

- **Độc lập 100%**: Hoàn toàn miễn phí, không yêu cầu đăng nhập, không cần server đám mây trả phí.
- **Tự động nhận diện phụ đề**: Tự động tải và đồng bộ phụ đề gốc YouTube (CC / Auto-generated ASR).
- **Làm sạch phụ đề**: Tự động loại bỏ các thẻ `>>`, `[Âm thanh]`, `[Sound]`, nhãn ngữ âm thừa trước khi đọc.
- **Dịch thuật tốc độ cao**: Tích hợp Google Translate Batch đa luồng, dịch toàn bộ phụ đề trong vài mili-giây.
- **Giọng đọc tiếng Việt chất lượng cao**: Sử dụng giọng đọc Microsoft Edge-TTS Neural (Hoài My, Nam Minh) mượt mà, diễn cảm.
- **Điều chỉnh âm lượng thông minh**: Tự động cân bằng âm lượng video gốc và âm lượng thuyết minh.

## 🚀 Hướng Dẫn Cài Đặt (Developer Mode)

1. Tải repository này về máy tính (hoặc `git clone https://github.com/TaiLoiZzzz/VietDubbing.git`).
2. Mở trình duyệt Google Chrome, truy cập: `chrome://extensions/`.
3. Bật **Chế độ dành cho nhà phát triển (Developer mode)** ở góc trên bên phải.
4. Bấm vào nút **Tải tiện ích đã giải nén (Load unpacked)**.
5. Chọn thư mục chứa tiện ích này.
6. Mở bất kỳ video nào trên YouTube và bấm nút lồng tiếng để thưởng thức!
